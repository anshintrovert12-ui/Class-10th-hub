# Class 10th Study Hub — Reference UI

This build is a UI-first recreation of the supplied Class 10th Study Hub reference.

## Included
- Reference-style header, hero, six resource cards, progress panel and footer
- Light/Dark mode
- Responsive sidebar
- Navigation between sections
- Flash-card flip interaction
- Settings: text size, festival modes, clear memory
- Subject/chapter selector placeholders for the content layer

## Run
Open `index.html` in Chrome/Edge/Firefox.

No paid service or server is required for this UI build.
