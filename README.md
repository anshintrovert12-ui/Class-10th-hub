# Class 10th Study Hub — Logic Build

This version adds real client-side state and calculations.

## Automatic logic
- Chapter completion is saved in localStorage.
- Subject percentage = completed chapters / total chapters for that subject.
- Overall percentage = average of the six subject percentages.
- Quiz attempts increment after a submitted quiz.
- Mock Tests Taken increments once per subject when that subject's mock is completed.
- Average Score = average of all completed quiz/mock scores.
- Quiz: 25 questions, 5-minute timer, required attempt before Next, correct/wrong feedback, auto-submit.
- Mock: 80 questions, 30-minute timer, required attempt before Next, correct/wrong feedback, auto-submit.
- Clear Memory resets saved state.
- Theme/text size/festival settings are persisted.
- Flash-card flipping and seven mini-game shells are functional.
